# 迷你我的世界 · Mini Minecraft

一个用 HTML5 + JavaScript + [Three.js](https://threejs.org/) 写的单文件 3D 体素沙盒小游戏，简易复刻《我的世界》。无需后端、无外部图片素材（所有方块纹理都由 Canvas 程序化生成）。

▶ **在线试玩：https://amorahabe1.github.io/mini-minecraft/**

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 点击画面 | 开始游戏（锁定鼠标） |
| W A S D | 移动 |
| 鼠标 | 转动视角 |
| 空格 | 跳跃 |
| Shift | 奔跑 |
| 鼠标左键 | 破坏方块 |
| 鼠标右键 | 放置方块 |
| 1-5 / 滚轮 | 切换方块（草方块、泥土、石头、木头、树叶） |
| Esc | 暂停 / 释放鼠标 |

## 特性

- 48×48 的噪声起伏地形，包含草方块、泥土、石头和随机生成的树木
- 第一人称视角，带重力、跳跃和方块碰撞
- 准星指向的方块会显示描边高亮，交互距离约 6 格
- 不能把方块放在自己身体里
- 按区块合并网格、只渲染外露的面，性能友好

## 本地运行

直接用浏览器打开 `index.html` 即可（需要联网从 CDN 加载 Three.js）。
