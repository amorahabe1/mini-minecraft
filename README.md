# 我的世界 · 网页复刻版（Mini Minecraft）

用 **Three.js + 原生 ES Modules + Web Worker** 在浏览器里尽量 1:1 复刻《我的世界》Java 版的核心玩法与操作手感。无需安装、无需构建，打开网页即可游玩。

👉 **在线游玩：<https://amorahabe1.github.io/mini-minecraft/>**

> 本项目为非官方的学习/致敬作品，与 Mojang / Microsoft 无关。所有方块纹理、物品图标、生物模型和音效都是代码**程序化生成**的原创内容，未使用任何官方素材。

---

## ✨ 功能一览

### 世界
- **无限世界**：16×16 区块、高度 128，随玩家移动在 Web Worker 中异步生成 / 网格化，远处区块自动卸载（可调渲染距离 2–16 区块）
- **种子**：输入数字或任意文字，同一种子生成同一世界
- **生物群系**：平原、森林、桦木森林、沙漠、积雪的针叶林、山地、海洋 / 深海、沙滩
- **地形**：大陆噪声 + 丘陵 + 山脊，洞穴（意面洞穴 + 奶酪洞穴）、地下岩浆湖、基岩层
- **矿石**：煤、铁、金、红石、钻石，按真实高度分布成矿脉；沙砾、黏土、沙石
- **植被**：橡树、桦树、云杉（可跨区块生成）、草丛、蒲公英、虞美人、枯萎的灌木、仙人掌
- **村庄**：平原 / 沙漠村庄（沙漠用砂岩），以钟和水井为中心的土径路网，大小木屋（橡木门、床、楼梯屋顶、窗户、工作台、箱子、火把）、农田（耕地 + 水渠 + 不同生长阶段的小麦）、灯柱；`/locate village` 查找最近的村庄
- **洞穴蜘蛛网**：洞穴顶部偶尔出现蜘蛛网（减速，用剑破坏可得线）
- **天气**：晴天 / 降雨 / 雷暴按 Java 版天气周期（随机持续时间、雨量平滑过渡），雨天天空与光照变暗、雨幕与雨声（室内变闷），寒冷生物群系与高山下雪，沙漠不降水；雷暴中随机落雷（闪电照亮天空、雷声、5 点伤害、劈中苦力怕变为闪电苦力怕）
- **方块更新**：水 / 岩浆流动（水源、流动等级、下落，无限水源规则），岩浆遇水变黑曜石/圆石，沙子和沙砾受重力下落，花草/火把失去支撑会掉落，草方块蔓延与枯死，树苗长成大树，砍树后树叶自然凋零

### 画面
- 16×16 像素风原创纹理（纹理数组 + Mipmap）
- **平滑光照 + 环境光遮蔽（AO）**，天空光与方块光分离计算（火把 14、荧石 15、岩浆 15、燃烧的熔炉 13）
- **昼夜循环**（20 分钟一天）：太阳、月亮、星空、日出日落的霞光、天空颜色与雾的渐变、方块世界随时间变暗
- 像素云层、距离雾、水下雾 / 岩浆视野
- 方块选择框、10 级挖掘裂纹、破坏粒子
- 第一人称手臂与手持物品（参照原版的挥动 / 切换物品 / 进食动画），第三人称（F5，背后 / 正面）
- 视角摇晃、疾跑 / 飞行时 FOV 变化、受伤镜头晃动

### 操作手感（按原版 20 TPS 物理复刻）
- 步行 4.317 m/s、疾跑 5.612 m/s、潜行 1.3 m/s，原版的重力、跳跃、空气阻力、地面摩擦、冰面打滑
- 疾跑跳跃加速、潜行不会从方块边缘掉落、游泳 / 上浮、岩浆中缓慢移动
- 创造模式双击空格飞行、着地自动结束飞行
- 生存触及距离 4.5 格，创造 5 格

### 生存模式
- 生命值、饥饿值、饱和度、消耗度（原版 1.11+ 回血规则：饱和度快速回血 / 饱食缓慢回血 / 饥饿掉血）
- 摔落伤害、溺水（氧气泡）、岩浆伤害、窒息、虚空
- **按住鼠标挖掘**，挖掘时间完全按原版公式：硬度 × 工具类型 × 工具材质（木 / 石 / 铁 / 钻石 / 金），需要合适工具才能掉落矿物；水下、空中挖掘变慢
- 工具耐久度、攻击冷却（1.9+）、暴击、疾跑击退
- 方块掉落物（会弹跳、漂浮、合并、被吸取），死亡掉落全部物品，重生
- **盔甲**：皮革 / 锁链 / 铁 / 金 / 钻石 头盔、胸甲、护腿、靴子；物品栏盔甲槽、右键快速穿戴、HUD 盔甲值；按 Java 公式计算盔甲值与盔甲韧性减伤，受伤磨损耐久（摔落 / 溺水 / 饥饿等伤害不经过盔甲）；第三人称与物品栏预览显示盔甲
- **弓与箭**：按住右键拉弓（拉弓动画、FOV 缩放），力度公式与 Java 一致，满弓暴击（暴击粒子）、箭受重力与阻力、插在方块上可捡回、耐久 384；合成弓（木棍 + 线）、箭（燧石 + 木棍 + 羽毛）
- **床**：红 / 白床，放置为两格；夜晚或雷暴中右键睡觉（附近有怪物 / 距离太远 / 被阻挡时给出原版提示），睡觉跳过到早晨并结束降雨；右键床设置重生点，床被破坏后重生点失效
- **门**：橡木门，两格高，按 Java 规则自动选择门铰链（相邻门组成双开门），右键开关，生物（村民）会开门
- **台阶 / 楼梯**：橡木、白桦木、云杉木、圆石、石、石砖、砂岩、红砖 8 种材料；台阶可放上半 / 下半、两片合成双层台阶；楼梯按视线朝向放置，点击方块上半部分放置倒置楼梯；玩家与生物可以直接走上台阶（0.6 格自动登高）
- **耕种**：锄头开垦耕地、种植小麦种子（草丛 1/8 概率掉落）、按 Java 生长速度生长、骨粉催熟、小麦合成面包；铲子把草方块铲成土径

### 创造模式
- 瞬间破坏、无限方块、飞行、无敌
- 创造模式物品栏：分类标签页（建筑方块、装饰性方块、工具、战斗用品、食物、原材料、搜索、生存物品栏）、搜索、销毁格

### 物品栏 / 合成 / 容器
- 9 格快捷栏 + 27 格背包，每组最多 64
- 原版点击规则：左键拿起/放下/交换、右键拿一半/放一个、Shift+点击快速移动、按住拖动均分/逐个放置、双击收集同类、数字键与快捷栏交换、Q 丢弃
- 2×2 随身合成 + **工作台 3×3 合成**（40+ 条原版配方：木板、木棍、工作台、熔炉、箱子、火把、全套工具与剑、桶、砖块、石砖、矿物块等，支持镜像）
- **熔炉**：燃料燃烧时间与烧炼进度按原版（每件 10 秒），熔炉点燃时会发光
- **箱子**：27 格存储
- 桶：舀水 / 舀岩浆 / 倒出
- 食物：按住右键进食（1.6 秒），苹果、面包、生熟猪排 / 牛肉 / 羊肉、腐肉

### 生物
- 猪、牛、羊、**鸡**：随机漫步、看向玩家、被打会逃跑，会自然刷新在草地上，掉落肉类 / 皮革 / 羊毛 / 羽毛（鸡缓慢下落、不受摔落伤害）
- **僵尸**：夜晚或黑暗处刷新，追击并攻击玩家，白天在阳光下燃烧，掉落腐肉
- **骷髅**：按 Java 远程攻击 AI 拉弓射箭（15 格射程、左右绕圈走位、太近会后退），白天燃烧（雨中不燃烧），掉落骨头和箭
- **苦力怕**：靠近玩家 3 格内开始点燃（膨胀、闪白、嘶嘶声），1.5 秒后爆炸；玩家远离 7 格取消；爆炸按 Java 射线算法破坏方块（掉落概率 1/威力）、按遮挡比例造成伤害与击退；被闪电击中变为闪电苦力怕（威力翻倍）；掉落火药
- **村民**：在村庄中生成并在钟附近活动，白天闲逛、傍晚到钟附近聚集，夜晚开门回家、走到床边；敲钟会让村民躲回屋里
- 怪物刷新按 Java 规则（亮度 / 方块光照 / 雷暴判定，生物权重）

### 其他
- 主菜单、世界列表（创建 / 进入 / 重命名 / 删除）、选项（视野、渲染距离、灵敏度、亮度、音量、音乐、视角摇晃、云、反转鼠标、界面尺寸）、暂停菜单、死亡界面
- **自动存档**到浏览器 IndexedDB（每 30 秒、暂停、退出时），保存方块修改、玩家位置 / 背包 / 状态、时间、箱子和熔炉内容
- 程序合成的音效（脚步、挖掘、破坏、放置、受伤、进食、生物叫声……）与偶尔响起的轻柔钢琴背景音乐
- F3 调试界面（坐标、朝向、区块、光照、生物群系、FPS 等）
- 聊天与命令

## 🎮 操作说明

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| 鼠标 | 转动视角 |
| `空格` | 跳跃 / 游泳上浮 / 飞行上升 |
| 双击 `空格` | 开启/关闭飞行（创造模式） |
| 左 `Shift` | 潜行（不会从边缘掉落）/ 飞行下降 |
| 左 `Ctrl` 或 双击 `W` | 疾跑 |
| 鼠标左键（按住） | 挖掘方块 / 攻击生物 |
| 鼠标右键 | 放置方块 / 使用物品 / 打开工作台、熔炉、箱子 / 开关门 / 睡觉 / 敲钟 / 穿戴盔甲 / 进食（按住）/ 拉弓（按住，松开射箭） |
| 鼠标中键 | 选取方块 |
| `1`–`9` / 滚轮 | 切换快捷栏 |
| `E` | 打开 / 关闭物品栏 |
| `Q` / `Ctrl`+`Q` | 丢弃一个 / 丢弃整组 |
| `T` 或 `/` | 打开聊天 / 输入命令 |
| `F1` | 隐藏界面 |
| `F3` | 调试信息 |
| `F5` | 切换第一 / 第三人称视角 |
| `Esc` | 暂停菜单（保存并退出也在这里） |

**物品栏中**：左键拿起 / 放下，右键拿一半 / 放一个，`Shift`+点击快速移动，按住拖动均分，双击收集同类物品，悬停时按数字键与快捷栏交换，按 `Q` 丢弃。

**命令**：

```
/gamemode creative|survival   切换游戏模式（也可用 c / s / 1 / 0）
/time set day|noon|night|midnight|<数值>
/tp <x> <y> <z>               支持 ~ 相对坐标
/give <物品英文ID或中文名> [数量]   例如 /give diamond_pickaxe、/give 火把 64
/summon <生物> [x y z]        pig|cow|sheep|chicken|zombie|skeleton|creeper|villager|lightning_bolt
/weather clear|rain|thunder [秒]
/locate village               查找最近的村庄
/seed  /kill  /spawn  /spawnpoint  /clear  /help
```

> 小提示：浏览器里 `Ctrl+W` 会关闭标签页。点击菜单里的「全屏」后游戏会锁定键盘，就可以放心用 `Ctrl` 疾跑了（或者直接双击 `W`）。离开页面前会弹出确认，世界也会自动保存。

## 🛠️ 技术实现

- **无构建步骤**：纯静态文件，`index.html` 通过 import map 加载仓库内的 Three.js r164（`vendor/three.module.js`），可直接部署到 GitHub Pages
- `js/worldgen.js`：Simplex 噪声地形、生物群系、洞穴、矿石、树木（Worker 中运行）
- `js/village.js`：村庄布局（网格化的确定性生成，跨区块拼接）
- `js/mesher.js`：区块网格化（面剔除、AO、平滑光照、BFS 光照传播、液体高度、交叉模型、火把）（Worker 中运行）
- `js/world.js`：区块加载/卸载与优先级调度、方块读写、方块更新（液体、重力、支撑）、随机刻
- `js/render.js`：自定义 GLSL3 着色器（纹理数组、光照曲线、雾）、天空、选择框、物品模型
- `js/physics.js` / `js/entities.js` / `js/player.js`：原版移动公式、AABB 碰撞、生物 AI、掉落物
- `js/textures.js`：全部像素纹理与图标的程序化绘制
- `js/ui.js` / `css/style.css`：HUD、物品栏、菜单（原版风格 GUI，自动缩放）
- `js/audio.js`：WebAudio 合成音效与音乐
- `js/storage.js`：IndexedDB 存档

本地运行：

```bash
git clone https://github.com/amorahabe1/mini-minecraft.git
cd mini-minecraft
python3 -m http.server 8000   # 需要通过 http 访问（ES Modules / Worker）
# 打开 http://localhost:8000
```

需要支持 WebGL2 的现代桌面浏览器（Chrome / Edge / Firefox / Safari 15+），使用键盘和鼠标操作。

## 与原版的差异（尚未实现）

红石电路、下界与末地、附魔与经验、多人游戏、触屏操作；村民交易 / 职业 / 繁殖、铁傀儡、铁门、楼梯拐角形状、火（闪电不会点火）、鸡下蛋等。

本次复刻的简化：
- 锁链盔甲与原版一样不能合成（创造模式物品栏或 /give 获取）
- 村庄间距比原版更密（约每 20 区块一个），村民不单独存档（重新进入时按床数在村中心重新生成）
- 村民寻路为基于门和床位置的路点导航，而非完整 A* 寻路
- 只有单人模式，因此“所有玩家睡觉”即玩家本人睡觉
